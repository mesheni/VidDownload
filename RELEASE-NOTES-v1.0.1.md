# VidDownload 1.0.1 — что нового с версии 0.8.1

Этот выпуск собирает всё, что появилось после `v0.8.1`: новое окно конвертера на FFmpeg, предпросмотр перед загрузкой, переезд на Fluent-дизайн и десятки исправлений.

## Конвертер FFmpeg (новое окно)

- Перекодирование любых медиафайлов в **MP4, MKV, MOV, AVI, WebM, FLV, WMV, TS**; режим **«только аудио»** (MP3, AAC, FLAC, OPUS, WAV, M4A); **пакетная конвертация** списком файлов с общим прогрессом.
- Аппаратные энкодеры **NVENC / AMF / QSV**: приложение реально проверяет работоспособность каждого кодера коротким тестовым кодированием — в списке остаются только те, что работают на вашей машине (просто наличие в `-encoders` ничего не гарантирует).
- Опции качества и пресетов подбираются под конкретный кодек: CRF для x264/x265/VP9/AV1, `-cq` для NVENC, `-global_quality` для QSV, `-qp` для AMF, `-cpu-used` для VP9/AV1. В список попадают только кодеки, совместимые с выбранным контейнером; субтитры записываются так, как умеет контейнер.
- Предпросмотр итоговой ffmpeg-команды, drag&drop файлов, отмена, прогресс с таймкодами.
- Не зависает при перезаписи существующего файла и не «молчит» при ошибках: причина показывается в окне и пишется в лог.

## Скачивание

- **Предпросмотр перед загрузкой** (`yt-dlp -J`): обложка, название, канал, длительность; для одиночного видео — выбор конкретного формата, для плейлиста — выбор элементов («выбрать всё / ничего»). Если предпросмотр не удался, можно скачать без него.
- **Приватные видео**: куки из Chrome / Edge / Firefox / Opera или файл cookies.txt; поддержка прокси.
- Встраивание обложки и метаданных; субтитры с конвертацией в SRT; скачивание **фрагмента по таймкодам**; **архив загрузок** (уже скачанное пропускается); ретраи; качество аудио при извлечении.
- **Очередь переживает перезапуск**: незавершённые загрузки сохраняются в `queue.json` и восстанавливаются в состоянии паузы.
- Пакетный импорт ссылок из .txt и drag&drop ссылок на окно.

## Интерфейс

- Полный переезд на **WPF-UI 4.3 (Fluent Design, Mica)**: новые окна, диалоги и уведомления вместо HandyControl; список очереди виртуализирован.
- **Темы Авто / Светлая / Тёмная** — переключатель в заголовке, выбор запоминается.
- Редкие настройки переехали в **отдельное окно настроек** (шестерёнка): язык, сворачивание в трей, мониторинг буфера обмена, лимит параллельных загрузок, сеть, папка логов.
- **Действие после очереди**: ничего / выключение / сон / гибернация.
- **Single-instance**: повторный запуск разворачивает уже открытое окно.
- Справка: быстрый старт, плейлисты, субтитры, конвертер, горячие клавиши, решение проблем.
- История: поиск, открытие файла/папки, удаление записи, пагинация «Показать ещё», экспорт в CSV (совместим с Excel).
- Прогресс-бары скруглены («пилюля») и окрашены по статусу: синий — загрузка, зелёный — готово, красный — ошибка.

## Обновления и сопровождение

- **Updater.exe самообновляется** вместе с приложением (аргумент `--updater-src`).
- FFmpeg обновляется из **стабильной ветки** BtbN вместо nightly: ночные сборки требуют более нового драйвера GPU и «роняли» NVENC на машинах со свежим железом и старым драйвером.
- CI: модульные тесты гоняются на каждый push в master и каждый PR; по тегу `v*` собираются MSI-инсталлятор и portable-версия (вместе с Updater.exe) в GitHub Releases.
- **137 модульных тестов**: аргументы yt-dlp и конвертера, парсеры прогресса и метаданных, версии, таймкоды, очередь и её персистентность.

## Основные исправления

- Падение при открытии истории и исчезание сводки очереди при 3+ загрузках.
- Зависание конвертера при перезаписи файла; «Unrecognized option 'crf'» на аппаратных кодерах; молчаливые ошибки конвертации.
- NVENC, «сломавшийся сам» после автообновления FFmpeg (причина — nightly-сборка).
- Layout очереди и конвертера, системные кнопки дочерних окон, цвет прогресс-баров.
